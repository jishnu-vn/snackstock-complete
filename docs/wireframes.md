# UI wireframes

## Dashboard
`Header and navigation` → `Product count | Order count | Low-stock alerts` → `quick-start guidance`

## Products
`Search input` → `add/edit product form` → `product table with edit and delete`

## Orders
`Status filter` → `order table: customer, items, status, status selector`

## New order and low stock
`Customer form + product/quantity line items + create order` and a separate table of products where `stockQuantity <= reorderLevel`.
